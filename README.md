## 📋 Bewerbungstracker - DevOps-Projekt

Eine moderne Webapplikation zur Verwaltung und Nachverfolgung von Bewerbungsprozessen.

Über das Projekt
Der Bewerbungstracker hilft dir dabei, den Überblick über deine Bewerbungen zu behalten. Verfolge den Status jeder Bewerbung, notiere wichtige Termine und behalte alle relevanten Informationen an einem Ort.
Features

  - Bewerbungen verwalten: Erstelle, bearbeite und lösche Bewerbungseinträge
  - Status-Tracking: Verfolge den aktuellen Stand (Beworben, Angenommen, Abgelehnt, Keine Antwort, etc.)
  - Übersichtliche Darstellung: Dashboard mit allen Bewerbungen auf einen Blick
  - Detaillierte Informationen: Speichere Unternehmen, Position, Datum, Ansprechpartner und Notizen
  - Moderne UI: Responsive Design für Desktop und Mobile
